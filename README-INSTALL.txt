RAILWAY EXAM HUB — CHAPTERS 03–20
=================================

This ZIP contains 18 standalone HTML study pages for Chapters 3–20.
Chapters 1 and 2 are intentionally not included.

IMPORTANT:
1. Extract this ZIP.
2. Upload all 18 .html files to the SAME GitHub repository folder as group-d.html.
3. In group-d.html, make each chapter's list item link to the matching filename.
4. Keep the chapter names and order already used on your website.
5. Test each link after GitHub Pages publishes.
