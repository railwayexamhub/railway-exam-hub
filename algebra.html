Algebra

RRB Group D Mathematics • Chapter 15

About this chapter

Algebra uses letters and symbols to represent numbers and relationships.

Study tip: Read the rules, practise the worked examples, then attempt the quiz without looking at the notes.

1. Key concepts and rules

  • A variable represents an unknown or changing number.
  • Like terms have the same variable part and powers.
  • Use the distributive property to remove brackets.
  • An equation remains balanced when the same operation is applied to both sides.

2. Important formulas and reminders

a(b+c) = ab+ac
a²−b² = (a−b)(a+b)
(a+b)² = a²+2ab+b²
(a−b)² = a²−2ab+b²
For ax+b=c: x=(c−b)/a, a≠0

3. Solved examples

Example 1: Solve 3x + 5 = 20.

3x = 15, so x = 5.

Answer: x = 5

Example 2: Expand 2(x+4).

Multiply 2 by each term inside brackets.

Answer: 2x + 8

Example 3: Factorise x²−9.

Use difference of squares: x²−3².

Answer: (x−3)(x+3)

4. Exam tips

  • Write down the given values before selecting a formula.
  • Check that units are consistent.
  • Do calculations step by step and simplify the final answer.
  • Estimate the result to catch arithmetic mistakes.
  • Practise questions under a time limit after learning the method.
