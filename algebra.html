Algebra

RRB Group D Mathematics · Chapter 15

About this chapter

Algebraic expressions, identities, factorisation and linear equations. This chapter page is designed for online revision and practice on Railway Exam Hub.

Key concepts and rules

  • Like terms have the same variables raised to the same powers.
  • a(b+c) = ab+ac.
  • (a+b)² = a² + 2ab + b².
  • (a−b)² = a² − 2ab + b².
  • Solve an equation by performing the same operation on both sides.

Solved examples

Practice concept 1

Solve: x + 7 = 15.

Answer: 8

Subtract 7 from both sides: x = 15 − 7 = 8.

Practice concept 2

Expand (a+b)².

Answer: a² + 2ab + b²

Use the identity (a+b)² = a² + 2ab + b².

Practice concept 3

If 3x = 21, find x.

Answer: 7

Divide both sides by 3: x = 21/3 = 7.
